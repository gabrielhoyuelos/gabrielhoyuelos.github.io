# Página personal de Gabriel Hoyuelos

Sitio académico estático en inglés, sin dependencias ni pasos de compilación.

## Archivos

- `index.html`: contenido de la página.
- `styles.css`: tipografía, colores y diseño adaptable a celulares.
- `.nojekyll`: permite servir los archivos directamente con GitHub Pages.

## Editar

Modificá los textos de `index.html` y guardá los cambios en la rama `main`. Para cambiar la apariencia, editá `styles.css`. Podés abrir `index.html` en un navegador para revisar la página localmente.

## Publicar en GitHub Pages

1. Usá el repositorio público `gabrielhoyuelos/gabrielhoyuelos.github.io`.
2. Colocá estos archivos en la raíz de la rama `main`.
3. En **Settings → Pages → Build and deployment**, elegí **Deploy from a branch**.
4. Seleccioná **main** y **/ (root)**, y guardá.
5. Cuando termine el despliegue, la página estará en `https://gabrielhoyuelos.github.io/`.

Cada cambio guardado en `main` actualizará la página automáticamente. El contenido inicial no incluye foto, correo, CV ni documentos de tesis; pueden agregarse cuando estén disponibles.
